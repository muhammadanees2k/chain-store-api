ChainStore E-Commerce Engine

A high-performance Django REST Framework API featuring a dual-gateway financial architecture. Engineered with strict state management, JWT authentication, and zero-trust blockchain verification.

View Swagger UI Docs Access API Root

RESTful Core

A fully relational E-Commerce API managing Products, Collections, Carts, and Orders. Leverages Djoser for stateless JWT user authentication, optimized database prefetching, and Cloudinary media management.

Fiat Gateway

PCI-Compliant Stripe Checkout integration. Utilizes raw payload extraction to cryptographically verify asynchronous webhooks, ensuring strict idempotency and database integrity.

Web3 / MetaMask

Zero-trust cryptocurrency architecture. Frontend signs Sepolia ETH transactions; Django utilizes web3.py to pull ledger receipts directly from RPC nodes to prevent frontend manipulation.

How to Test the Payment Integrations

  1. 1
    Create an Order via API

    Use the Swagger UI (or Postman) to create a Cart, add items, and convert it into an Order. Take note of the generated order_id.

  2. 2
    Access the Secure Checkout UI

    Navigate to the dynamic frontend proof-of-concept page to interact with Stripe or MetaMask. Replace {id} with your Order ID:

    http://127.0.0.1:8000/store/orders/{id}/payment-page/
  3. 3
    Monitor the Verification

    Execute a payment. Observe the backend as Django cryptographically verifies the Stripe signature webhook, or queries the Sepolia Ethereum RPC for the Web3 transaction receipt before updating the database.
